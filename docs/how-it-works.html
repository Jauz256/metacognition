1
Install
One line to install. It asks nothing.
$ npx github:jazzs-thoughts/metacognition
installed: bin/ hooks/ claims.tsv timer every 30 min
3 hooks added to settings.json (your other hooks are kept)
running the checks once ...
metacognition GREEN: 11 of 11 rules held
macOS or Linux, Node 18 or newer. Thirty seconds later you see your first verdict.
2
Your rules
Your rules are sentences. A sentence cannot fail.
CLAUDE.md
- run the tests before every commit
- no console.log in shipped code
- answer first, details second
- one commit per change
- ask before touching 3+ files
The agent reads this file every session.

It can obey a line, or forget it, and nothing in the file can tell you which happened.

4
One check runs
Exit 0 means the rule holds. Exit 1 means it broke. Nothing in between.
idclaim, plain wordscheck command
tests-greenthe test suite passesbash tests/run.sh
no-consoleno console.log shipped! grep -rq console.log src
answer-firstthe answer is line onenode tools/answer-first.mjs
exit 0
Run one: the tests pass, the command exits 0, the rule holds.
exit 1
Run two, an hour later: a test broke, the command exits 1, the rule is RED. No opinion, no model, no maybe.

6
Session start
The agent sees the red rule before it sees your question.
$ claude
metacognition RED: 1 of 11 rules failed. tests-green is FALSE right now
 
> what should I work on?
First the red rule: the tests are failing. Run bash tests/run.sh and read the last line.
A hook prints the last verdict as the first line of every session. The agent cannot pretend everything is fine.
7
Corrections
Every correction is logged, word for word. The third time, it becomes a check.
"again, no console.log"
"redo, the console.log is still there"
"not what I asked. console.log!"
3 times = a pattern
idclaimcheck command
tests-greenthe test suite passesbash tests/run.sh
answer-firstthe answer is line onenode tools/answer-first.mjs
no-consoleno console.log shipped! grep -rq console.log src
A new row in claims.tsv. From now on the timer checks it 48 times a day, and the light shows whether the mistake comes back.
8
Red debt
A red rule older than 24 hours blocks the end of a turn until someone decides.
RED for 26 h   tests-green   the test suite passes
Two ways out, and both are decisions. Silence is not one of them.
Fixed it
node red-debt.mjs fixed "tests-green"
Not fixing it now, and why
node red-debt.mjs debt "tests-green"
"the flaky test waits for the vendor fix on Monday"
A debt receipt lasts 24 hours. Then it fires again. Nothing stays red by accident.

$ npx github:jazzs-thoughts/metacognition --uninstall
